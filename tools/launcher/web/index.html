    Overclock

    Multiplicadores por dominio de reloj. 1.00x = consola real. El ancla del ritmo es el campo de video, no el reloj de CPU: con overclock el juego hace mas trabajo por campo, pero los campos siguen saliendo a 59.94 Hz. Subirlo quita ralentizacion; tambien puede romper un juego que ate su logica al reloj.

    "Sin limite" no es un overclock: corre tan rapido como pueda el anfitrion y el juego va acelerado. El overclock por dominio si mantiene el ritmo de video.
