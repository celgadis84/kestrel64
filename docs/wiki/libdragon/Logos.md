# Libdragon logos

This page shows the libdragon logo in several variants. The logo was designed by Spooky Илюха and Cedar Branch, and it has been donated to the libdragon project. The font is Tschichold, which is licensed under the SIL Open Font License (OFL).

The logo can be reused freely by N64 applications using libdragon. While the license does not require it, we appreciate if you can add a "Made with Libdragon" screen or overlay in your ROMs.
