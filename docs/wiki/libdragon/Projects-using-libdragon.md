## Original homebrew games
* ClassiCube - Multi-platform Minecraft Classic / ClassiCube client with early N64 support, using libdragon - <https://github.com/ClassiCube/ClassiCube>
* n64_bullet_demo - Bullet physics example built with libdragon’s OpenGL implementation to create physics simulation - <https://github.com/alexvnesta/n64_bullet_demo>
* FlappyBird N64 - A demake of Flappy Bird using libdragon (2017) - <https://github.com/meeq/FlappyBird-N64>
* Happy Little Frog Game - An in-progress platformer made with libdragon & tiny3d - <https://github.com/s4Ys369/hlfg>
* N64-RPG - An in-progress RPG engine using libdragon - <https://github.com/breadbored/N64-RPG> 
* n64triangle - RDP triangle demo, using libdragon - <https://github.com/sp1187/n64triangle>
* Penguins Luv Melons - A homebrew game built with libdragon [w/ src] - <https://n64squid.com/homebrew/roms/penguins-luv-melons/>
* Vlak 64 - A reimplementation of the classic DOS game Vlak using libdragon - <https://github.com/thekovic/vlak64>
* BrewReality - A 3D flight sim tech demo built with libdragon, featuring 128x128 textures & dynamic sky and lighting - <https://github.com/SpookyIluha/BrewReality>
* Juic'n 64 - Game made for the 2020 N64 Homebrew Game Jam - <https://github.com/N64brew-Game-Jam-2020/Juicn-64>
* The GameJam 2024 ROM is a collection of 21 mini-games. Everything is done using libdragon - <https://github.com/n64brew/N64brew-GameJam2024-Template>

## Game ports
* Wolfenstein 64 - Source port of Wolfenstein 3D and Spear of Destiny, adapted from Wolf4SDL, using libdragon - <https://github.com/thekovic/wolfenstein64>
* LibdragonDOOM - Source port of the original DOOM to the Nintendo 64 using libdragon SDK - <https://github.com/thekovic/LibdragonDOOM>

## Other projects
* chip8 n64 - CHIP-8 emulator, using libdragon - <https://github.com/joshiggins/chip8-n64>
* sodium64 - SNES emulator for N64, using libdragon - <https://github.com/Hydr8gon/sodium64>
* mvs64 - A NeoGeo emulator for N64 - <https://github.com/rasky/mvs64>
* controllertest - A simple homebrew ROM built with libdragon to perform some basic controller tests - <https://github.com/max257612/controllertest>
* n64_controller_test - Another controller test ROM, built with libdragon - <https://github.com/Ryzee119/n64_controller_test>
